# alamo-db-releases

Alamo DB is now released from [Axel769/alamo-db](https://github.com/Axel769/alamo-db/releases):
source, downloads and the in-app updater all live there.

This repository only hosted the alpha builds while the source was private
(up to 0.1.0-alpha.12). Its last release carries the updater manifest that
points to the new repository, so that older installations still find the
update. It will be archived.
